# 项目诚实边界

## boundary

- 不连接真实电商平台库存，不保证商品实时可售。
- 不处理支付、退款、清结算或第三方平台下单，只创建订单意向。
- 到手价来自版本化静态规则与汇率快照，不宣称等于真实海关/结账价格。
- 固定离线商品快照不代表真实平台全量搜索效果。

## 必须由报告升级的能力

- 上下文 Token 降幅、信息保留率与稳定前缀率在 `context.json` 通过前为 `code_verified`。
- Kimi 工具选择、DAG 规划和 Fork 正确率在 `live.json` 通过前为 `code_verified`。
- 品类负例拒识在独立开发集校准并通过冻结测试集前不能写“可靠拒答”。
- Langfuse 只有存在一条完整主/子 Agent Trace 摘要后才能写“已验证全链路 Trace”。
- 未进行真实人工排障计时，不写 badcase 定位时间收益。
- 供应商不返回缓存 Token 时，不写 Prompt Cache 命中率，只写稳定前缀率。
