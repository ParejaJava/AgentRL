# 项目诚实边界

## boundary

- 不连接真实电商平台库存，不保证商品实时可售。
- 不处理支付、退款、清结算或第三方平台下单，只创建订单意向。
- 到手价来自版本化静态规则与汇率快照，不宣称等于真实海关/结账价格。
- 固定离线商品快照不代表真实平台全量搜索效果。

## 已验证但必须限定口径

- 上下文 Token 降幅只指 `agent_loop_only` 输入，压缩模型开销单列；当前 8 轮实验的 `full` 总 Token 高于 `off`，不得宣称总成本下降。
- Kimi 结果来自 12 条固定场景各重复 3 次，不等同于开放域任务成功率。
- 品类拒答阈值在独立开发集选择，90% 是 100 条冻结集中的负例拒识率，不等同于任意域外输入的拒答率。
- Langfuse 只证明抽样 Trace 可回读及结构完整度，不宣称全量遥测 100% 上传。
- 商品最终策略改善的是 MRR/NDCG；其 Recall 低于 lexical，不能写成“相较词法 Recall 提升”。
- 供应商不返回缓存 Token，因此不写 Prompt Cache 命中率，只写同 Epoch 稳定前缀率。
- 未进行真实人工排障计时，不写 badcase 定位时间收益。
